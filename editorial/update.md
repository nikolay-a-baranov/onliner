# Update Existing Project

1. В Project Instructions замени текст содержимым `project.md`.
2. Открой вкладку Sources.
3. Удали старые версии файлов, которые заменяешь.
4. Загрузи файлы из папки `sources/`.
5. Не загружай `setup.md`, `update.md`, `roadmap.md`, `prompt.md`, `workflow.md` и файлы из `input/`.
6. Если ChatGPT видит две версии файла с одинаковым смыслом, удали старую версию.
7. После обновления открой новый чат в этом Project и проверь один `*_source.json` из `input/`.
