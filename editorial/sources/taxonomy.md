# Taxonomy

Этот файл — source of truth для классификации `draft.v1`: `target.section` и `target.categories`.

`source.json` остается extraction-слоем и может содержать только подсказки. Финальная классификация выполняется перед сборкой `draft.json`. Launchpad importer не должен принимать редакционные решения: он применяет только то, что явно передано в `draft.json`, и только если это совпадает с текущей админкой.

## Classification Flow

Перед генерацией `draft.v1`:

1. Определи `target.section` по содержанию материала, `source.url`, `source.site`, `editor.notes` и явным подсказкам во входе.
2. Выбери `target.categories` только из allowed categories для выбранного `target.section`.
3. Используй exact label: строка в `target.categories` должна полностью совпадать с названием рубрики в WordPress.
4. Не создавай новые рубрики и не придумывай локальные варианты названий.
5. Если уверенность низкая, лучше оставить `target.categories` пустым массивом или минимальным набором и добавить практическую задачу в `audit.editor_todo`.

## Allowed Sections

Допустимые значения `target.section`:

```text
people
auto
tech
realt
money
sport
```

Если раздел не удается определить уверенно, используй пустую строку `""` и добавь в `audit.editor_todo`: `Уточнить раздел перед публикацией.`

## Host And Section Aliases

Host aliases — только подсказки, а не окончательное решение. Если содержание противоречит host, ориентируйся на смысл материала и добавь сомнение в `audit.editor_todo`.

```text
people.onliner.by → people
auto.onliner.by → auto
tech.onliner.by → tech
realt.onliner.by → realt
money.onliner.by → money
sport.onliner.by → sport
```

Редакционные aliases:

```text
Люди → people
Авто → auto
Технологии → tech
Недвижимость → realt
Деньги → money
Спорт → sport
```

## Category Selection Rules

`target.categories` — редакционные рубрики материала, а не технические флаги публикации.

Технические/операционные категории (`Авторы Onliner`, `Избранное`, `Сайдбар`, `Срочно в номер!`) существуют в админке, но агент не должен выбирать их автоматически. Используй их только если вход содержит явное редакторское указание. Для промо/выделения/флагов предпочитай явные поля `draft.options`, если они предусмотрены `payload.md`.

`Разное`, `Последние новости`, `Новости спорта` и похожие широкие рубрики допустимы только как fallback, если более точной рубрики в выбранном section нет и section выбран уверенно.

## Exact Label Rule

`target.categories` должен содержать только строки из allowed categories выбранного `target.section`.

Не нормализуй названия рубрик самостоятельно:

```text
Бизнес          ✅
бизнес          ❌
Business        ❌
Деньги / Бизнес ❌
```

Если подходящей рубрики нет в списке, не создавай ее. Оставь `target.categories = []` или выбери только безопасную минимальную рубрику, если она точно разрешена для section.

## Confidence Rule

Используй рубрику только при высокой уверенности.

Низкая уверенность:
- материал смешивает несколько тем;
- source host не совпадает с содержанием;
- вход содержит legacy/непроверенную категорию;
- подходящей exact category нет в списке;
- категория выглядит как тег, тема или SEO-ключ, а не рубрика WordPress.

При низкой уверенности:

```json
{
  "target": {
    "section": "",
    "categories": []
  },
  "audit": {
    "editor_todo": [
      "Уточнить раздел и рубрику перед публикацией."
    ]
  }
}
```

Если `target.section` уверен, но category не уверена:

```json
{
  "target": {
    "section": "money",
    "categories": []
  },
  "audit": {
    "editor_todo": [
      "Уточнить рубрику раздела Деньги перед публикацией."
    ]
  }
}
```

## Responsibility Boundary

- ChatGPT Project классифицирует материал и предлагает `target.section`/`target.categories` по этому файлу.
- Launchpad importer применяет только exact-matched categories, которые реально есть в админке.
- Launchpad importer не создает новые рубрики.
- Если importer не может применить category, это должно стать warning для автора, а не молчаливым игнорированием.
