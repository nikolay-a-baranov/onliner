# Годовая аналитика Ledger

Status: active
Last reviewed: 2026-10-31

## Sources

- Пользовательский запрос на отдельную годовую инфографику с динамикой нагрузки и фильтрами разделов и типов.
- Месячные crawler JSON схемы `onliner-publications` v2 из `local-data/ledger/`.

## Objective

Отдельная страница `/ledger/year/` сравнивает месяцы одного года, показывает изменение объёма работы выбранного корректора и команды и применяет общие фильтры ко всем показателям.

## Scope

- Автозагрузка локального годового набора через индекс Ledger.
- Множественная загрузка JSON в опубликованной версии.
- Год, корректор, раздел, лэйаут и тип как общие фильтры.
- Итоговые карточки, месячный график, структура по разделам и обзор команды.
- Разрывы графика для не собранных в конкретном месяце разделов.

## Non-goals

- Начисление зарплаты и изменение месячной таблицы.
- Публикация локальных JSON в GitHub Pages.
- Автоматическая классификация неизвестного автора ревизии как корректора.

## Current milestone

## Acceptance criteria

- Локально страница автоматически открывает доступный год.
- Онлайн принимает несколько JSON за один выбор.
- Фильтры одинаково влияют на карточки, график, структуру и командные мини-графики.
- Несобранный раздел не выглядит как нулевой объём.
- Страница адаптируется к узкому экрану без наложений.

## Verification

- `node tools/build-registry-smoke.js`
- `npm run verify`
- Проверка полного diff и собранного `ledger/year/index.html`.

## Progress and evidence

- 2026-10-31 — подтверждены девять совместимых выгрузок января–сентября 2026 года; во всех используется схема v2 и одинаковые поля объёма, раздела и лэйаута.
- 2026-10-31 — собран первый вариант `/ledger/year/`: локальный индекс и пакетная загрузка, годовые карточки, общий помесячный график, фасеты, структура разделов и мини-графики команды; `node tools/build-registry-smoke.js` и полный `npm.cmd run verify` прошли.
- 2026-10-31 — селекты, внутренний шаг панелей и кластеры синхронизированы с месячной страницей; числа до 10 000 и трёхбуквенные подписи месяцев получили отдельное компактное форматирование.
- 2026-10-31 — ручная загрузка переведена в отложенное состояние; карточка выбранного корректора получила фоновое выделение и фиксированную верхнюю строку «имя слева — объём справа».
- 2026-10-31 — повторный обход ревизий при каждом фильтре устранён кэшем на пару «месяц × корректор»; общий сброс перенесён после заголовка состава по паттерну месячной страницы.
- 2026-10-31 — загрузочная панель оставлена без описания, команда вынесена в полноширинную адаптивную сетку, а рабочая область годового графика опущена и уплотнена снизу.
- 2026-10-31 — общий график переведён на единую шкалу всех корректоров; цветная легенда управляет видимостью отдельных линий, числовые подписи остаются только на линии выбранного корректора.
- 2026-10-31 — карточки команды собраны в фиксированную сетку 3 × 2 на широком экране с переходом на две и одну колонку на средних и узких экранах.
- 2026-10-31 — подписи значений общего графика распространены на все видимые линии и получили отдельный переключатель показа; эмоджи и счётчики состава соединены без зазора.
- 2026-10-31 — мини-графики команды снова растянуты до боковых краёв карточек при сохранении текстовых отступов; процент изменения получил подсказку с первым и последним сравниваемыми месяцами.
- 2026-10-31 — основной график расширен до краёв текстовой области; подписи значений по умолчанию скрыты и независимо переключаются для линии кликом по любой её точке.
- 2026-10-31 — пересчёт кластеров состава переведён на тот же diffusion fade-out/fade-in механизм и motion-токены, что используются в месячном Ledger.

## Decision log

- 2026-10-31 — годовая аналитика вынесена со страницы месячного отчёта, чтобы их разные задачи и состояния фильтров не конкурировали в одном интерфейсе.
- 2026-10-31 — отсутствие выбранного раздела в `data.sections` трактуется как недоступные данные и разрыв графика, а не нулевой результат.
